# Default block textures

The builder uses block textures from [Pixel Perfection Community Edition](https://github.com/Athemis/PixelPerfectionCE/tree/28e38cab7c1f03f86364ef704f705bebcc13cb3d), originally created by XSSheep and updated by StonePendant, freejusticehere, Stingraych, Nova_Wostra, lazerl0rd, and the community.

The textures in this distribution are licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). The archive contains only the upstream top-level block PNG files, copied without modifications, and the upstream license and credits. It omits entity textures, custom block models, and animation metadata. The viewer renders a single frame for animated textures and applies foliage tint where applicable.

The source pack targets Java Edition 1.16.2. Newer blocks or unmatched designs can fall back to the builder's generated textures. Block geometry and Bedrock-to-Java mappings are provided by the builder.
